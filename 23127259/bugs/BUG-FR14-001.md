# BUG-FR14-001: Missing RBAC — Regular User Can Create/Update/Delete Categories

**Bug ID:** BUG-FR14-001  
**Feature:** FR-14 – Category Management CRUD  
**Student:** Nguyễn Tấn Thắng (23127259)  
**Severity:** 🔴 **HIGH** (Security Vulnerability)  
**Priority:** P1 — Must Fix  
**Status:** CONFIRMED  
**Confirmation Date:** September 2, 2026

---

## Summary

The Category CRUD endpoints (`POST/PUT/DELETE /api/categories`) lack **Role-Based Access Control (RBAC)** enforcement. Any authenticated user — including regular customers with `role = "user"` — can create, update, and delete product categories. Per the HW06 assignment specification (FR-14 in Pool C = Web Admin), these operations should be restricted to administrators only.

---

## Reproduction Steps

1. Start the SUT: `cd /Volumes/Thang/eshop-sut/backend && node server.js`
2. Login as regular user: `POST /api/login` with `{ "email": "test@eshop.com", "password": "Test1234!" }`
3. Use the returned JWT token as a regular user
4. Send: `POST /api/categories` with `Authorization: Bearer <userToken>` and body `{ "name": "User Created Category" }`
5. **Observed:** HTTP 200 OK with `{ "message": "Category created", "id": <n> }`
6. **Expected (per SRS):** HTTP 403 Forbidden

---

## Root Cause

In `server.js` lines 249-279, the category routes apply `authenticateToken` middleware (which only verifies JWT validity) but do **NOT** apply any role-checking middleware (no `isAdmin` function or `req.user.role === 'admin'` check).

```javascript
// server.js:249 - NO role check
app.post("/api/categories", authenticateToken, (req, res) => {
  const { name } = req.body;
  db.run("INSERT INTO categories (name) VALUES (?)", [name], function (err) {
    // ...
  });
});
```

---

## Security Impact

- **SEC-02 Violation:** Authorization & Role-Based Access Control
- **SEC-04 Adjacent:** Insecure Direct Object Reference — any user can target any category by ID for PUT/DELETE
- **Risk:** A regular customer could delete all product categories, corrupt the product taxonomy, or create spam categories

## Recommended Fix

Add an `isAdmin` middleware to all category CRUD endpoints:

```javascript
const isAdmin = (req, res, next) => {
  if (req.user.role !== 'admin') {
    return res.status(403).json({ error: 'Admin access required' });
  }
  next();
};

app.post("/api/categories", authenticateToken, isAdmin, (req, res) => { ... });
app.put("/api/categories/:id", authenticateToken, isAdmin, (req, res) => { ... });
app.delete("/api/categories/:id", authenticateToken, isAdmin, (req, res) => { ... });
```
