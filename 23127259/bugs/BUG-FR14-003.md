# BUG-FR14-003: No Existence Check — PUT/DELETE Succeed on Non-Existent Category IDs

**Bug ID:** BUG-FR14-003  
**Feature:** FR-14 – Category Management CRUD  
**Student:** Nguyễn Tấn Thắng (23127259)  
**Severity:** 🟡 **MEDIUM** (Silent Failure / Data Integrity)  
**Priority:** P2  
**Status:** CONFIRMED  
**Confirmation Date:** September 2, 2026

---

## Summary

The `PUT /api/categories/:id` and `DELETE /api/categories/:id` endpoints return HTTP 200 with success messages even when the target category ID does not exist in the database. The SUT does not check `this.changes` (SQLite's affected row count) to determine if any row was actually modified or deleted.

---

## Reproduction Steps

1. Login as admin
2. Send: `PUT /api/categories/99999` with body `{ "name": "Ghost" }`
3. **Observed:** HTTP 200 with `{ "message": "Category updated" }`
4. **Expected:** HTTP 404 Not Found
5. Send: `DELETE /api/categories/99999`
6. **Observed:** HTTP 200 with `{ "message": "Category deleted" }`
7. **Expected:** HTTP 404 Not Found

---

## Root Cause

In `server.js` lines 258-266 (PUT) and 269-277 (DELETE), the `this.changes` value from SQLite is not checked:

```javascript
app.put("/api/categories/:id", authenticateToken, (req, res) => {
  const { name } = req.body;
  db.run("UPDATE categories SET name = ? WHERE id = ?", [name, req.params.id], function (err) {
    if (err) return res.status(500).json({ error: err.message });
    // Missing: if (this.changes === 0) return res.status(404)...
    res.json({ message: "Category updated" });
  });
});
```

---

## Impact

- Update/Delete on deleted categories appear successful, misleading the client
- Double-delete succeeds without error
- Updating a zombie (non-existent) category reports success
- Can mask application bugs where wrong IDs are passed

## Recommended Fix

```javascript
db.run("UPDATE categories SET name = ? WHERE id = ?", [name, req.params.id], function (err) {
  if (err) return res.status(500).json({ error: err.message });
  if (this.changes === 0) return res.status(404).json({ error: 'Category not found' });
  res.json({ message: "Category updated" });
});
```
