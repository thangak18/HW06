# BUG-FR14-004: Unhandled Server Exception (HTTP 500) When Content-Type Header Is Omitted

**Bug ID:** BUG-FR14-004  
**Feature:** FR-14 – Category Management CRUD  
**Student:** Nguyễn Tấn Thắng (`23127259`)  
**Severity:** 🔴 **HIGH** (Unhandled Server Exception / Crash)  
**Priority:** P1  
**Status:** CONFIRMED  
**Confirmation Date:** September 2, 2026

---

## Summary

When a client sends a `POST /api/categories` request without the `Content-Type: application/json` header, Express middleware does not parse the raw body. Consequently, `req.body` is `undefined`. When the route handler attempts to destructure `const { name } = req.body;`, Node.js throws an unhandled `TypeError: Cannot destructure property 'name' of 'req.body' as it is undefined.`, resulting in an unhandled HTTP `500 Internal Server Error`.

---

## Reproduction Steps

1. Authenticate as admin: `POST /api/login` $\rightarrow$ obtain valid JWT
2. Send: `POST /api/categories` with:
   - Header: `Authorization: Bearer <adminToken>`
   - Header: `X-Student-Id: 23127259`
   - **Omit** the `Content-Type` header
   - Raw Body: `{"name": "No Content Type"}`
3. **Observed Status:** `500 Internal Server Error`
4. **Server Terminal Output:**
   ```
   TypeError: Cannot destructure property 'name' of 'req.body' as it is undefined.
       at /Volumes/Thang/eshop-sut/backend/server.js:250:11
   ```
5. **Expected Status:** HTTP `400 Bad Request` or HTTP `415 Unsupported Media Type` with a clean JSON error response (`{"error": "..."}`). The server should never crash or throw uncaught 500 exceptions on missing headers.

---

## Root Cause

In `server.js` lines 249–250:
```javascript
app.post("/api/categories", authenticateToken, (req, res) => {
  const { name } = req.body;  // Crashes if req.body is undefined!
```
Because `bodyParser.json()` only processes requests matching its default `type: 'application/json'`, requests without this header leave `req.body` as `undefined`. Accessing properties on `undefined` causes a fatal runtime TypeError in JavaScript.

## Recommended Fix

Safely guard `req.body` or default to an empty object:
```javascript
app.post("/api/categories", authenticateToken, (req, res) => {
  if (!req.body) {
    return res.status(400).json({ error: "Missing or invalid Content-Type; expected application/json" });
  }
  const { name } = req.body;
  // ...
});
```
