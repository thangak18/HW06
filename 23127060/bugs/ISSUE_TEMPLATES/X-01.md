## Mức độ

🔴 Critical

## Yêu cầu bị vi phạm

`SEC-06, FR-04, FR-12` — theo `eshop-sut/README.md`

## Ảnh hưởng

Endpoint nhận trường `role` từ body và ghi thẳng vào CSDL. Bất kỳ tài khoản nào cũng tự trở thành admin bằng một request. Kết hợp với việc các API admin khác chỉ kiểm sự tồn tại của token, đây là đường leo thang quyền trọn vẹn.

## Bước tái hiện

```bash
curl -i -X POST 'http://localhost:3000/api/register' \
     -H 'Content-Type: application/json' \
     -H 'X-Student-Id: 23127060' \
     -d '{"name": "Attacker", "email": "api.x01.attacker.23127060@test.local", "password": "Api1234!"}'
```

## Kết quả thực tế

```http
HTTP/1.1 200
Content-Type: application/json; charset=utf-8

{"message":"User registered successfully","id":3}
```

## Kết quả mong đợi

Theo `SEC-06, FR-04, FR-12` trong đặc tả của hệ thống.

## Đề xuất sửa

Bỏ `role` khỏi danh sách trường được phép cập nhật. Chỉ cho phép đúng ba trường `name`, `phone`, `shipping_address` như SRS FR-04 quy định.
