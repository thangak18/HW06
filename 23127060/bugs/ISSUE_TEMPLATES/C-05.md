## Ảnh hưởng

Dòng `if (row.id % 2 === 0) row.price = row.price.toString()` đổi kiểu dữ liệu theo tính chẵn lẻ của khóa chính. Client cộng tiền sẽ nhận `"28000000" + 1000` ra chuỗi `"280000001000"`. Bug chỉ lộ ra khi so sánh hai response với nhau; test riêng từng response đều thấy hợp lệ.
