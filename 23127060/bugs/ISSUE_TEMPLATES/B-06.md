## Yêu cầu bị vi phạm

`FR-09` — theo `eshop-sut/README.md`

## Ảnh hưởng

SRS FR-09 điều kiện C3 ghi rõ "Tổng đơn hàng **>= (lớn hơn hoặc bằng)** `min_order_amount`". Code viết `if (total_amount > coupon.min_order_amount)`. Đơn có giá trị bằng đúng ngưỡng bị từ chối. Đây là lỗi biên kinh điển, và nó rơi đúng vào trường hợp người dùng hay gặp nhất: mua vừa đủ ngưỡng để được giảm giá.

## Bước tái hiện

```bash
curl -i -X POST 'http://localhost:3000/api/apply-coupon' \
     -H 'Content-Type: application/json' \
     -H 'X-Student-Id: 23127060' \
     -d '{"code": "SAVE10", "total_amount": 300001, "user_id": 1}'
```
